# M4 — 動的処理（LSM / 最適執行 / HJB）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 動的計画法を「1 反復ずつ手で送って見る」3 シーン: Longstaff–Schwartz（後ろ向き回帰と継続価値フィット）、Almgren–Chriss（リスク回避 λ 別の執行軌道とフロンティア）、Merton HJB（価値関数 V(w,t) と最適比率 π*(w)）。

**Architecture:** M2 で確立した「1 step = 1 後ろ向き反復」「Snapshot は縮約値、格子は `SurfaceModel` の面」パターンをそのまま使う。core は header-only・割り当ては init のみ。LSM の回帰は小さな正規方程式（K ≤ 8）なので `math/linsolve.hpp`（部分ピボット LU、固定上限）を追加する。

**Tech Stack:** C++20 header-only core、Catch2 v3、ImPlot（2D）、`SurfaceView`（3D）。

**規約:** `CLAUDE.md` と M1〜M3 の約束（`std::in_place`、`panel_common.hpp`、`RateMeter`、`prev_seq_` ガードは `seq < prev_seq_`、`ImGuiSliderFlags_AlwaysClamp` + ウィジェット後クランプ、`surface()` は全フィールドを書く、NaN は `!(v > lo)` 形）。

## 型契約

### Task 1 — LSM（`namespace quantviz::core`）

```cpp
// math/linsolve.hpp — 小さな密行列の連立一次方程式（部分ピボット LU、n ≤ kMaxN = 16、作業配列は呼び手）
bool linsolve(std::size_t n, std::span<double> a /* n×n row-major, 破壊される */, std::span<double> b /* n, 解で上書き */,
              std::span<std::size_t> piv /* n */) noexcept;   // 特異なら false
// pricing/lsm.hpp — Longstaff–Schwartz（American put/call、GBM、アンチセティック対）
enum class LsmBasis : std::uint8_t { Power, Laguerre };
struct LsmParams { double s0, K, T, r, sigma; OptionType type; std::size_t n_paths /* 偶数 */, n_steps, n_basis /* 2..8 */;
                   LsmBasis basis = LsmBasis::Laguerre; std::uint64_t seed; };
struct LsmResult { double price, std_error; double european_price /* 同パスの MC */; std::size_t exercised_paths; };
class Lsm {   // ヒープは init でのみ（paths n_paths×(n_steps+1)、cashflow、回帰の作業配列）
public:
    void init(LsmParams p);                       // パス生成（対で Z, −Z）。t = T（後ろ向き反復の開始）
    bool step_backward();                         // 1 時点分の回帰 + 行使判定。t=0 に着いたら no-op で false
    std::size_t remaining() const noexcept;  std::size_t current_step() const noexcept;
    LsmResult result() const noexcept;            // 現時点までの部分結果（全時点処理後が最終価格）
    std::span<const double> path(std::size_t i) const noexcept;        // i 番目のパス（n_steps+1 点）
    std::span<const double> spots_at(std::size_t step) const noexcept; // 全パスの S（列）
    std::span<const double> continuation_coeffs() const noexcept;      // 直近時点の回帰係数（n_basis）
    double continuation_value(double s) const noexcept;                // 直近時点のフィット
    double quantile_at(std::size_t step, double q) const noexcept;     // S の分位（描画用。nth_element は作業配列で）
};
```
LSM-01: アンチセティック対の Z の和が厳密に 0（パス生成器を露出するか、`path(2i)`, `path(2i+1)` の対数リターン和で検査）。LSM-02: American put（S0=K=100, T=1, r=0.05, σ=0.2, N=20000, M=50, Laguerre 3）が `FdmCn`（N=M=200）の価格の 95 % CI 内。LSM-03: ≥ 同パス European MC。LSM-04: n_basis 2→5 で価格差が CI 内。LSM-05: seed 固定で bit 一致。LSM-06: σ=0 で決定的ペイオフ（SE=0）。LSM-07: N を 4 倍で SE が半分（±20 %）。

### Task 2 — Almgren–Chriss（`core/exec/almgren_chriss.hpp`）

```cpp
struct AcParams { double X /* 株数 */, T, sigma /* 価格ボラ（絶対, /√時間） */, eta /* 一時インパクト */, gamma /* 恒久インパクト */, epsilon /* 固定コスト */, lambda /* リスク回避 */; std::size_t n_steps; };
double ac_kappa(AcParams p) noexcept;                                      // √(λσ²/η)（η̃ = η − γτ/2 の補正は別関数で明示）
std::size_t ac_trajectory(AcParams p, std::span<double> x_out) noexcept;   // x_j（残量）, n_steps+1 点。λ=0 は線形（TWAP）
std::size_t ac_trades(AcParams p, std::span<double> n_out) noexcept;       // n_j = x_{j−1} − x_j
struct AcCost { double expected, variance; };
AcCost ac_cost(AcParams p) noexcept;                                       // 閉形式 E[C], V[C]
AcCost ac_cost_mc(AcParams p, std::uint64_t seed, std::size_t n_sim) noexcept;   // MC（テスト用、割り当てなし: 逐次）
std::size_t ac_frontier(AcParams base, std::span<const double> lambdas, std::span<AcCost> out) noexcept;
```
AC-01 閉形式軌道と一致、AC-02 Σ trades = X、AC-03 λ=0 で TWAP、AC-04 λ↑ で前倒し、AC-05 閉形式 vs MC（4 SE）、AC-06 フロンティア λ↑ でコスト↑・分散↓、AC-07 κ の定義一致。

### Task 3 — Merton HJB（`core/exec/hjb_merton.hpp`）

```cpp
struct HjbParams { double mu, r, sigma, gamma /* CRRA */, T; double w_min, w_max; std::size_t n_w, n_t; };
class HjbMerton {   // V(w,t) を w 格子、時間後ろ向き。各時刻・各 w で π を最適化（1 次元、解析解 π*=(μ−r)/(γσ²) を初期値に黄金分割 or ニュートン）。
public:
    void init(HjbParams p);                       // 終端 V(w,T) = U(w) = w^{1−γ}/(1−γ)（γ=1 は log）
    bool step_backward();                         // 1 時間ステップ（陰的 or 十分小さい dt の陽的 + 上流差分。安定性を文書化）
    std::size_t remaining() const noexcept;  double time() const noexcept;
    std::span<const double> wealth() const noexcept;  std::span<const double> values() const noexcept;
    std::span<const double> optimal_fraction() const noexcept;   // π*(w) 現時点
    double value_at(double w) const noexcept;
};
double merton_fraction(HjbParams p) noexcept;   // 解析解 (μ−r)/(γσ²)
double merton_value(HjbParams p, double w, double t) noexcept;   // 閉形式 V(w,t) = U(w) e^{(1−γ)(r + (μ−r)²/(2γσ²))(T−t)}
```
HJB-01 π* が全 w で定数（1e-3、境界近傍は除外を明記）、HJB-02 凹、HJB-03 単調増加、HJB-04 終端条件、HJB-05 格子細分で解析解への誤差減少、HJB-06 時間整合。
