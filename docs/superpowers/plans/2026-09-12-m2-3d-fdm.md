# M2 — 3D サーフェス・FDM 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 自作 OpenGL サーフェス描画を作り、Crank–Nicolson（+ PSOR）の後ろ向き反復を「手で 1 ステップずつ送れる 3D アニメ」にする。合わせてパラメトリックなボラ面シーンと、Greeks シーンの Γ(S,T) の 3D 化。

**Architecture:** 5 層と Snapshot/Command の双対は維持。グリッド大の状態は Snapshot（リング）ではなく **`bridge::TripleBuffer`（最新 1 枚）** で渡す。そのために `Model` 契約を任意拡張する：`SurfaceModel` 概念（`Surface` 型 + `surface(Surface&) const`）を満たす Model に対して `Runner` が `TripleBuffer<Surface>` を持ち、`poll_surface()` で描画側が最新面を取る。3D 描画は vizcore（GUI 非依存）の行列・カメラ・メッシュ計算と、viz 層の GL レンダラ（FBO → `ImGui::Image`）に分ける。GL 関数は `glfwGetProcAddress` で自前ロード（外部ローダ依存なし。GL 3.0 core 相当: VAO/VBO/EBO/FBO/シェーダ）。

**Tech Stack:** C++20 header-only core/bridge/vizcore、Catch2 v3、ImGui 1.91 / ImPlot 0.16、OpenGL 3.0（GLSL `#version 130`、macOS は 150）。

**規約:** `CLAUDE.md`。M1 で確立した約束（`ClockControlState` + `clock_panel.hpp`、`RunnerScene` の `std::in_place` 構築、`RateMeter` / `setup_follow_axis` / `kPanelTop` の共通ヘルパ、Reset 時の `prev_seq_` ガード、NaN は `!(v > lo)` 形で拒否）に従う。

## 型契約

### Task 1 — TripleBuffer と SurfaceModel

```cpp
// bridge/triple_buffer.hpp — SPSC「最新 1 枚」交換。書き手はブロックしない、読み手は裂けない。
template <class T>  // trivially copyable（static_assert）
class TripleBuffer {
public:
    /// 書き手専用: 現在のバックスロットへの参照（書き込み → publish）
    T&   back() noexcept;
    void publish() noexcept;                 // バックを「最新」として公開し、次のバックを確保
    /// 読み手専用: 新しい面があれば out に取り込み true。無ければ false（TRIPLE-04）
    bool read(T& out) noexcept;
    /// どちらからも: 未読の新データがあるか
    bool has_new() const noexcept;
private:
    std::array<T, 3> slots_; std::atomic<std::uint32_t> state_;  // [back|middle|front] index + "new" bit
};
// model_concept.hpp
template <class M> concept SurfaceModel = Model<M> && requires(const M& cm, typename M::Surface& s) {
    typename M::Surface; requires std::is_trivially_copyable_v<typename M::Surface>;
    { cm.surface(s) } noexcept;     // 現在の面を s に書く（ヒープなし）
};
// runner.hpp（追加）
struct RunnerConfig { ...; std::size_t surface_every = 1; };   // k ステップに 1 回 surface を publish
template <Model M, ...> class Runner {
    // SurfaceModel<M> のときだけ有効（if constexpr / requires）:
    bool poll_surface(typename M::Surface& out) noexcept;   // 描画スレッド。最新 1 枚。無ければ false
    std::uint64_t surfaces_published() const noexcept;
};
```
RUNNER-09（`tests/test_runner.cpp` に追記、`[runner][unit]`）: SurfaceModel を `tick()` で k ステップ回すと `poll_surface` が最新面を 1 枚だけ返し（古い面は捨てられる）、`surface_every` の間引きが効く。非 SurfaceModel の Runner はサイズが増えない（`static_assert(sizeof(Runner<CounterModel>) == 以前と同じ)` 相当の検査でよい）。

### Task 2 — GL 数学・カメラ・メッシュ（vizcore、`namespace quantviz::viz::gl`）

```cpp
// gl/math.hpp — 列優先 float 4×4（OpenGL 規約）
struct Vec3 { float x, y, z; };
struct Mat4 { std::array<float, 16> m; static Mat4 identity(); };
Mat4 operator*(const Mat4&, const Mat4&);
Vec3 transform_point(const Mat4&, Vec3);                       // 同次除算込み
Mat4 look_at(Vec3 eye, Vec3 target, Vec3 up);
Mat4 perspective(float fovy_rad, float aspect, float znear, float zfar);
std::optional<Mat4> inverse(const Mat4&);
// gl/camera.hpp — 軌道カメラ
struct OrbitCamera {
    Vec3  target{0,0,0}; float distance = 3.f; float yaw = 0.f; float pitch = 0.5f;   // rad
    float fovy = 0.9f; float znear = 0.05f; float zfar = 100.f;
    void  rotate(float dyaw, float dpitch) noexcept;   // pitch は (−π/2+ε, π/2−ε) にクランプ。距離不変（GL-02）
    void  zoom(float factor) noexcept;                 // distance *= factor（下限あり）
    Vec3  eye() const noexcept;
    Mat4  view() const noexcept;  Mat4 projection(float aspect) const noexcept;
    Vec3  project(Vec3 world, float aspect) const;     // NDC
    std::optional<Vec3> unproject(Vec3 ndc, float aspect) const;   // GL-03
};
// gl/surface_mesh.hpp — N×M グリッド → 頂点・法線・インデックス（CPU 側）。構築時だけ確保
class SurfaceMesh {
public:
    SurfaceMesh(std::size_t n_x, std::size_t n_y);         // 頂点 n_x·n_y、三角形 2(n_x−1)(n_y−1)
    void set_axes(std::span<const float> xs, std::span<const float> ys);   // x,y は固定
    void set_z(std::span<const float> z_row_major);         // z だけ更新（再確保なし: SURF-05）
    void update_normals() noexcept;                         // 中心差分 → 正規化（SURF-03/04/06）
    struct Vertex { float x, y, z, nx, ny, nz; };
    std::span<const Vertex>        vertices() const noexcept;
    std::span<const std::uint32_t> indices() const noexcept;
    std::size_t n_x() const; std::size_t n_y() const;
};
```

### Task 3 — Thomas 法と CN/PSOR（`namespace quantviz::core`）

```cpp
// math/tridiag.hpp — a: 下対角(n−1), b: 対角(n), c: 上対角(n−1), d: 右辺(n) → x（in-place 可）。作業配列は呼び手が渡す
bool tridiag_solve(std::span<const double> a, std::span<const double> b, std::span<const double> c,
                   std::span<const double> d, std::span<double> x, std::span<double> work) noexcept;  // ゼロピボットで false
// pricing/fdm_cn.hpp — BS PDE を S 均等格子 [0, S_max]、N 空間分割、M 時間分割で CN
struct FdmGrid { double s_max; std::size_t n_space; std::size_t n_time; };
struct FdmParams { double K, T, r, sigma, q; OptionType type; bool american; double psor_omega = 1.2;
                   std::size_t psor_max_iter = 10000; double psor_tol = 1e-10; };
class FdmCn {   // ヒープは init でだけ確保
public:
    void init(FdmGrid g, FdmParams p);                 // 満期ペイオフをセット、t = T
    bool step_backward();                              // 1 時間ステップ。t が 0 なら no-op で false（FDM-11）
    std::size_t remaining() const noexcept;  double time() const noexcept;
    std::span<const double> spots() const noexcept;    // 格子点 S_i
    std::span<const double> values() const noexcept;   // 現在時刻の V(S_i)
    double value_at(double s) const noexcept;          // 線形補間
    double delta_at(double s) const noexcept;          // 中心差分（FDM-05）
    double exercise_boundary() const noexcept;         // American: V == 本源的価値 の境界 S*（put: 最大の S、call: 最小の S）。無ければ NaN
    std::size_t last_psor_iterations() const noexcept; bool last_psor_converged() const noexcept;   // FDM-10
};
```
境界条件: put は V(0,t) = K e^{−r(T−t)}（American は K）, V(S_max,t) = 0；call は V(0,t)=0, V(S_max,t) = S_max e^{−q(T−t)} − K e^{−r(T−t)}。FDM-02: N=M=200 で BS と相対 1e-3（ATM 付近）。FDM-03: N,M を 2 倍で誤差 ≈ 1/4（比が 3〜5 の範囲）。

### Task 4 — ボラ面コア（SSVI）

```cpp
// pricing/vol_surface.hpp — Gatheral–Jacquier SSVI: w(k,θ) = θ/2 (1 + ρ φ k + sqrt((φ k + ρ)² + 1 − ρ²)), φ(θ) = η / θ^γ
struct SsviParams { double sigma_atm = 0.2; double rho = -0.3; double eta = 1.0; double gamma = 0.5; };
double ssvi_total_variance(double k, double T, SsviParams p) noexcept;   // θ = σ_atm² T
double ssvi_implied_vol(double k, double T, SsviParams p) noexcept;      // sqrt(w / T)
bool   ssvi_calendar_arbitrage_free(SsviParams p) noexcept;              // 既定パラメータで true（VOLSURF-02 の根拠）
SsviParams ssvi_clamp(SsviParams p) noexcept;                            // ρ∈(−1,1), η>0, γ∈[0,1], σ>0（NaN は既定へ）
```
VOLSURF-01: 全 (k,T) で IV > 0。VOLSURF-02: 既定で総分散が T で単調増大（固定 k 列で検査）。VOLSURF-03: ρ=0 で w(k) = w(−k)（相対 1e-12）。

### Task 6 — ボラ面シーン

`VolSurfaceModel`: `Snapshot{ t, SsviParams params, double k_min,k_max,t_min,t_max, seq }`（≤128 B）, `Surface{ static constexpr kK=64, kT=32; std::array<float,kK> ks; std::array<float,kT> ts; std::array<float,kK*kT> iv; }`（row-major [iT][iK]）。`Param{ kSigmaAtm=1, kRho=2, kEta=3, kGamma=4 }`。`step(dt)` は t を進めるだけ（面はパラメータ変更時に再計算、`surface_every` で publish）。VOLSURF-04（`[volsurf][contract]`）: SurfaceModel 充足、面は固定サイズ POD、SetParam(ρ) で面が変わる。パネル: 「IV surface」（3D, `SurfaceView`）、「Smile @ T」（2D、選択した T の断面、ImPlot）、Control（4 スライダー + 時計）。

### Task 7 — FDM シーン

`FdmAmericanModel`: `Snapshot{ t_remaining, iteration, remaining, status(0 ok/1 psor 未収束), s0, v_at_s0, delta_at_s0, exercise_boundary_now, std::array<double,256> spots, values（現在時刻の V(S) を 256 点に補間）, std::array<double,256> boundary_t（時間軸: 各反復での S*）, std::uint32_t boundary_len, seq }`（≈ 6 KB, SnapCap 256）。`Surface{ kS=200, kT=200; std::array<float,kS> spots; std::array<float,kT> times; std::array<float,kS*kT> values; std::uint32_t filled_rows; }`（満期側から埋まる。未計算行は 0）。1 `step(dt)` = 1 後ろ向き反復（`dt` は無視）。`Param{ kStrike=1, kRate=2, kSigma=3, kDividend=4, kAmerican=5, kOptionType=6, kOmega=7 }`。`Reset` は `init` し直し（満期ペイオフ）。FDMSCENE-01..04 は `03_tdd_spec.md` の通り。パネル: 「V(S,t) surface」（3D）、「V(S) now」（2D: V、本源的価値、BS European 参照、S* と S0 の縦線）、「Exercise boundary S*(t)」（2D: 反復ごとの S*）、Control（K r σ q, American/European, Call/Put, ω, 時計 — StepOnce で 1 反復）。`steps_per_second` 既定 20（1 反復 = 1 ステップなので遅めに）。

**実装時の改定（レビューで承認）**: 行使境界は 3D 面上のラインではなく専用の 2D ウィンドウに描く（レンダラは三角形のみ描画し、ライン用の追加パスは M2 の範囲外）。`SnapCap` は 256 ではなく 64（Snapshot 6.3 KB × 64 = 400 KB、Runner は別に 3 面 ≈ 480 KB を保持）。SetParam は即座に `init` し直して掃引を最初からやり直し、`seq` を 0 に戻す（PDE の係数は掃引途中で変えられない）。
